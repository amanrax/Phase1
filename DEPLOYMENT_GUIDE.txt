🤖 AUTOMATED APK BUILD (RECOMMENDED)
═══════════════════════════════════════════════════════════════

Since we're in GitHub Codespaces (no Android SDK), the best way
to build APK is through GitHub Actions which has SDK pre-installed.

📝 STEPS TO GET YOUR APK:

1. Commit and push changes to dev branch:
   ─────────────────────────────────────────────────────────────
   cd /workspaces/Phase1
   git add .
   git commit -m "feat: Phase-2 v2.0.0 - Mobile build configuration"
   git push origin dev
   ─────────────────────────────────────────────────────────────

2. GitHub Actions will automatically:
   • Build the React app
   • Sync with Capacitor
   • Build Android Debug APK
   • Upload as artifact

3. Download APK from GitHub:
   • Go to: https://github.com/amanrax/Phase1/actions
   • Click on your workflow run
   • Download "CEM-Farmer-Android-APK" artifact
   • Extract: CEM-Farmer-v2.0.0-debug.apk

4. Install on Android device:
   • Enable "Unknown Sources" in Android settings
   • Transfer APK to phone
   • Tap to install

⚠️  IMPORTANT NOTES
═══════════════════════════════════════════════════════════════

1. PC IP ADDRESS
   Your PC IP is set to: 192.168.1.66
   If your IP changes:
   • Edit: frontend/.env.production
   • Rebuild APK

2. DOCKER MUST BE RUNNING
   Before using the APK, ensure Docker is running on PC:
   docker ps
   # Should show farmer-backend, celery-worker, farmer-redis

3. SAME WIFI NETWORK
   Phone and PC must be on the same WiFi network

4. FIREWALL
   Ensure port 8000 is open on your PC:
   # Windows:
   netsh advfirewall firewall add rule name="FastAPI" dir=in action=allow protocol=TCP localport=8000
   
   # Linux:
   sudo ufw allow 8000/tcp

5. HTTP vs HTTPS
   Current config uses HTTP for dev (not secure)
   For production, use HTTPS with SSL certificate

📦 WHAT HAPPENS WHEN YOU PUSH
═══════════════════════════════════════════════════════════════

2. Starts Ubuntu runner with Android SDK
3. Installs Node.js 20 and JDK 17
4. Installs npm dependencies

8. Creates: CEM-Farmer-v2.0.0-debug.apk
9. Uploads APK as downloadable artifact
10. Available for 30 days

Total time: ~5-10 minutes

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

If APK can't connect to backend:

  1. Check Docker on PC:
     docker ps
     
  2. Test from PC browser:
     http://192.168.1.66:8000/api/health
     
  3. Test from phone browser:
     http://192.168.1.66:8000/api/health
     ^ Should show: {"status":"ok"}
     
  4. If not working:
     • Check PC IP: ipconfig (Windows) or ifconfig (Linux)
     • Update frontend/.env.production if IP changed
     • Rebuild APK
     • Check firewall allows port 8000
     • Ensure phone and PC on same WiFi
