PROBLEM:
═══════════════════════════════════════════════════════════════
Your mobile app is showing "Cannot reach server" because the 
Codespaces port 8000 is set to PRIVATE by default.

Mobile apps outside Codespaces can't access private ports!

SOLUTION: Make Port 8000 PUBLIC
═══════════════════════════════════════════════════════════════

STEP 1: Open the PORTS panel in VS Code
────────────────────────────────────────────────────────────────
  • Look at the bottom of VS Code
  • Click on "PORTS" tab (next to TERMINAL)
  • You should see port 8000 listed

STEP 2: Change Port Visibility to PUBLIC
────────────────────────────────────────────────────────────────
  • Find port 8000 in the list
  • Right-click on port 8000
  • Select "Port Visibility" → "Public"
  
  OR
  
  • Click the lock icon 🔒 next to port 8000
  • Change from "Private" to "Public"

STEP 3: Verify the Public URL
────────────────────────────────────────────────────────────────
After making it public, you should see a URL like:

  https://automatic-doodle-wqp6gjqwxvqhggvw-8000.app.github.dev

Test it in your browser - should show: {"status":"ok"}

STEP 4: Rebuild the APK
────────────────────────────────────────────────────────────────
Once port is public, push your changes:

  git add .
  git commit -m "fix: configure Codespaces backend URL for mobile"
  git push origin dev

Wait for GitHub Actions to build the new APK with correct URL.
